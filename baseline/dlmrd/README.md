# DL-MRD 六指标预测基线

依据 Chen 等的 [DL-MRD 论文](https://doi.org/10.1016/j.tre.2024.103822)第4章和 Table 2 独立实现，参考[作者仓库固定版本](https://github.com/HKU-Smart-Mobility-Lab/DL-MRD-Broadcasting/tree/1e627ad895f92a06382d7ec01571aeeb5fa5f48c)，未复制作者代码。此处将其适配为本项目的联合定价与匹配半径预测基线，不是原论文广播模式实验的逐项复现。

## 网络与数据

输入为4个历史决策步，每步24维；当期包含28维数值上下文及独立网格 token，覆盖本网格与邻区状态、全城状态和6个网格的价格/半径。历史经3层 Transformer encoder，再与上下文表示拼接、展平，由6个独立线性头分别预测冒泡请求数量、订单呼出率、司机接单率、订单完成率、匹配等待时间和平台收益。

默认隐藏维度64、注意力头数8、前馈维度128、dropout=0，前馈激活为ReLU，历史采用因果注意力掩码。论文明确给出3个注意力模块及独立任务头，但未完整给出这些实现参数；此处将其作为本项目适配设置记录。保留论文的编码器—上下文拼接—线性头结构，不加入 Transformer decoder。线性拼接的上下文分支限制了状态与候选动作之间的非线性交互，不能据此预先承诺学到准确的非线性动作收益排序。

前馈层采用ReLU，历史使用因果注意力掩码，均属于具体实现选择。序列始终按批次、时间、特征排列，避免不同样本之间混用注意力。

沿用 `datasets_grid6_low_mixed47k_20261029/dataset_manifest.json` 的47,000条完整仿真划分，按完整轨迹隔离训练、验证、测试：

| 集合 | 仿真轨迹 | 监督样本 |
| --- | ---: | ---: |
| 训练 | 33,004 | 11,089,344 |
| 验证 | 6,948 | 2,334,528 |
| 测试 | 7,048 | 2,368,128 |
| 合计 | 47,000 | 15,792,000 |

这是现有数据约70%/15%/15%的划分，未重新采用论文的60%/40%划分。输入和六个标签的 min-max 参数仅用训练集拟合。网格编号按类别处理。

六指标沿用本项目数据口径：司机接单率不等于论文的司机利用率；匹配等待时间不等于接驾时间；平台收益与论文按已服务订单价格求和的定义也有区别。不同口径的绝对数值不能直接对照论文结果。

## 训练

```bash
python3 -m baseline.dlmrd.launch
```

默认 Adam、学习率 `1e-3`、无权重衰减、batch size `1024`，训练1000轮、不早停。每轮记录 `training_history.csv`；`latest.pt` 保存模型、优化器和WESM状态，用相同输出目录和配置重新启动时，从最近完成的轮次继续。验证集等权平均 MSE 最低的检查点保存为 `best_model.pt`。测试集在训练结束后评估，不用于模型选择。

WESM 对每个任务的 min-max MSE 按时间滞后做指数加权：`γ=0.1`，保留10个历史训练步，每10个训练步更新一次任务权重。历史加权误差较大的任务获得较大权重，归一化后六个权重和为1。权重参与当前任务损失加权，历史误差不跨批次反向传播。论文算法中的下标存在排版混用，这里依其文字定义按时间滞后衰减、按任务维归一化。

WESM 是预测任务的损失平衡方法，不是运营目标权重。`decision.select_actions` 提供逐网格候选枚举：默认最大化预测收益，也支持六指标适配的综合分数（训练集Min-Max归一化，等待负向，其余正向）。该分数保留正负号，不对其取绝对值；所有预测不裁剪。此接口不包含长程规划，也不保证全城联合最优。

```python
from baseline.dlmrd.model import DLMRDPredictor
from baseline.dlmrd.decision import select_actions

model = DLMRDPredictor.load("models/dlmrd_grid6_low47k_mps1000_20261117/best_model.pt")
actions = select_actions(model, features, price_values, radius_values)
```

`features` 必须为每个网格各一行历史及当前可观测特征，不含当前标签；联合动作列须与各网格动作一致。候选评分时其他网格动作固定为该输入上下文，返回的各行预测对应这一评分条件；闭环策略评估应另行固定场景与随机流。

每轮写入 `latest.pt` 和 CSV，暂停信号在当前完整轮次（含验证）结束后生效。再次执行相同启动命令可续训，完整恢复模型、Adam、WESM和随机状态；输出目录的训练配置与源码指纹需一致。

## 曲线与测试

```bash
python3 -m baseline.dlmrd.report models/dlmrd_grid6_low47k_mps1000_20261117
```

`paper_figures/` 输出600 dpi PNG和矢量PDF：完整训练曲线及右侧前100轮、六指标误差曲线、WESM权重曲线。纵轴为 **Min-max MSE**，保留原始观测，不做平滑；总体曲线是六任务等权平均，不是动态加权训练损失。

终测后生成 `test_results.csv`（MAE、RMSE、R²）和 `test_metrics` 图，与上一步观测值保持不变的 persistence 基线对照。图中比率误差用百分点表示，CSV保留原量纲。预测误差比较不等同于闭环运营收益比较。
