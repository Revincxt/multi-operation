# 离线多智能体策略学习

保留原始 **MA-IQL**、IQL-9 推理对照与已采用的 **MA-IQL+**。发布权重与加载示例见 [checkpoints](../checkpoints/README.md)，历史试验状态见 [方法状态](../docs/experiment_status.md)。

## 方法

**MA-IQL**：六区域各有一个局部策略，分别输出价格和半径分布；集中式双 Q 与 V 读取全城历史和状态，Q 额外读取完整联合动作。训练采用 expectile 价值回归、双 Q Bellman 回归、优势加权行为克隆和软目标更新。这是离散多智能体适配，不是官方 IQL 实现的直接复现。

原始设置为四期历史、660 维全城状态、γ=0.99、expectile=0.7、奖励除以 100。IQL-9 使用相同类型模型，在执行时限制到价格 `{1.4,1.6,1.8}` 与半径 `{1.5,2.0,2.5}` 的九种组合；它是独立标注的推理对照。

**MA-IQL+**：时序／空间共享表示、价格条件半径双头、结构化联合 Q，以及策略条件 TD 目标、局部反事实和联合动作保守正则。加入队列、司机、接驾取消和收益辅助任务；执行时直接使用策略，保留全部 110 种动作，不附加 Q 搜索。它复用结构化 Q 的训练初始化，因此相关价值模块与初始化权重仍有用途。

MA-IQL+ 初始化 74 已通过预定的两阶段评估；在额外 50 个确认种子上，相对 F3 增收 44.54 USD，配对 95% 区间 [17.07,72.44]。其余初始化没有同样稳定的优势，不能把该结果解释为所有训练重复均优于 F3。

## 数据与评估

- 复用完整轨迹划分，标准化器仅在训练数据拟合；既有 47k 与 100k 转移目录均保留。
- 状态包括历史动作与当前动作前状态，排除当期结果和未来订单。
- 共同预热 20 分钟，计分窗口为 05:20—10:00；F3 为价格 1.6、半径 2 km。
- 配对共享订单抽样、司机初态和预热；后续动作改变随机数调用，因此不声称完全相同的未来随机流。
- 报告每个种子的收益差和配对区间。当前仅一个订单日期，不代表跨日期泛化。

## 运行

```bash
python3 -m pip install -r baseline/requirements.txt

# 新建原始 MA-IQL 实验；数据需已存在
python3 -m offline_rl.train --device auto --steps 20000 \
  --output models/iql_new --workers 4

# 从相同配置的最近完整断点恢复
python3 -m offline_rl.train --device auto --steps 20000 \
  --output models/iql_new --workers 4 --resume
```

MA-IQL+ 使用 `offline_rl.train_conservative`，依赖本地完整 replay 与结构化 Q 初始化。`checkpoints/` 提供推理权重，不包含全部训练依赖。参数约定见各入口的 `--help`。新实验使用独立输出目录，恢复既有训练须保留其配置、源码指纹和采样状态。

## 模块

`data.py` / `prepare_collection.py` 构建转移，`iql.py` 实现基础算法，`conservative_policy.py` / `train_conservative.py` 实现 MA-IQL+，`evaluate.py` 提供共同观测与闭环评估。结构化价值、时空策略、种子隔离及统计函数仍被现行方法复用；本轮不删除这些依赖。

退役试验的专用权重已清理，原报告、采用记录和汇总统计留在本地，避免删除负结果后误报结论。
