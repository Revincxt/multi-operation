# 联合策略提取对照

研究问题：固定外生观测、价值学习与计算预算后，跨区域条件动作分布能否减少独立策略提取的协调损失？本轮不加入记忆网络，不实施 InSPO，不改变价格响应和匹配流程。

两种策略均读取660维全城历史与决策前状态，六区域参数独立，每区域有价格头及以自身价格为条件的半径头。独立版不读取当期其他区域动作；自回归版按0–5顺序读取当前决策步已经生成的前缀动作。训练使用记录前缀计算联合似然，执行使用自己的前缀，六区域动作生成完后统一施加。

前缀由每区域三个固定编码组成：实际候选价格/半径经固定范围归一化，加已知前缀标记。两版网络拓扑、名义参数量和初始化相同；独立版前缀恒为零，因此相关输入权重不活跃。批量区域矩阵计算与逐区域计算已做数值一致性测试，不共享区域参数。

每个初始化新建一套不要求可加的全城双Q/V，两种IQL actor共用相同价值估计、训练批次和优势权重。对应两个BC去掉优势权重，分别保留相同结构及初始化。这是IQL联合策略分布的适配，[原IQL论文](https://arxiv.org/abs/2110.06169)提供价值与策略损失；它不是[InSPO](https://ojs.aaai.org/index.php/AAAI/article/view/34099)的序贯智能体更新实现，也不声称单调改进保证。

## 预定试验

- 原47,000次轨迹及原划分，训练1,848,224条城市级转移，不改标签或重采集。
- 五个初始化42–46，每个固定10,000次更新，batch512，MPS；网络和价值均从随机参数训练。
- Actor隐藏256，每区域三层；联合critic隐藏256；Adam3e-4，actor余弦衰减；expectile0.7，优势系数3，奖励除100，gamma0.99，tau0.005。
- 全11价格×10半径，禁止本试验导出任何推理动作限制或固定策略回退。
- 使用固定最后一次更新，不搜索checkpoint。5,000/10,000步的留出NLL仅作诊断。
- 新验证种子50个，按训练初始化均衡分成每组10个；新测试种子100个，每组20个。所有种子在训练前固定，排除既有闭环回放；配对策略使用相同订单、司机初态与20分钟预热。
- 六个对照为F3、新独立IQL、新自回归IQL及对应两个BC、旧IQL-9。旧IQL-9只作历史参考；新模型均无掩码。
- 主要结果是自回归相对独立策略、相对F3的佣金差；使用先重采样训练初始化、再重采样其配对仿真种子的层级bootstrap。每个模型的环境种子不同，是均衡嵌套设计，不是5×100全交叉设计。
- 结构和部署checkpoint只按验证选择。只有验证平均比F3提高至少0.5%、层级区间为正，且测试相对F3和旧默认的层级区间为正，才额外进行50个新测试种子的单checkpoint确认；两项确认区间均为正才更新默认策略。

10,000次更新是本轮结构验证预算，不表示所有网络均已充分收敛。一个订单日期、五个训练初始化仍不足以证明跨日期或跨规模泛化。确定性逐头解码不保证全联合概率或全城价值全局最优。gamma0.99保持原训练目标以隔离结构因素，不折扣有限时域目标留作单独消融。

```bash
python3 -m offline_rl.train_joint --device mps --workers 4
python3 -m offline_rl.train_joint --device mps --workers 4 --resume
```

输出在`models/iql_joint_ablation_20261102/`：`protocol.json`固定种子、哈希及采用标准；各初始化保存完整优化器断点和四个策略；`validation/`、`test/`保留原始仿真、六指标对比及层级区间。训练曲线同时输出600dpi PNG和PDF/SVG。断点每1,000次更新保存；已完成时恢复命令不重复运行。

## 完成结果

五次独立训练及50个验证、100个测试种子均已完成。每个训练初始化对应20个测试种子，六种策略分别仿真，共600个测试回放；没有复用运营结果。评分区间为05:20–10:00，预热统一使用价格1.5、半径3公里。

| 策略 | 测试平均平台佣金（USD，↑） |
| --- | ---: |
| F3：价格1.6、半径2公里 | 7056.03 |
| 旧默认IQL-9（历史参考） | 6986.83 |
| 新独立IQL | 6800.40 |
| 新自回归IQL | 6800.40 |
| 对应独立BC / 自回归BC | 6800.40 |

自回归IQL相对F3为−255.64 USD（−3.62%），层级bootstrap 95%区间为[−287.54, −225.46] USD，100次配对中胜出2次。相对新独立IQL的收益差为0。四种新策略各有33,600次评分区间内网格决策，全部选择1.5/3公里。网络权重及概率分布并不相同，不能将相同argmax动作解释为未训练或复用结果。

本轮未通过预先规定的采用门槛，默认模型保持不变。该结果不支持“仅增加跨区域动作前缀就能改善现有数据上的闭环收益”；它也不是对所有自回归方法的否定，固定解码顺序、更新预算和当前数据均限制结论范围。

## 条件覆盖诊断

对训练集全部转移解码历史动作，筛选六区域过去四期均使用相同指定组合的状态：

| 四期全城历史 | 来源轨迹数 | 转移数 | 下一步记录的动作切换数 |
| --- | ---: | ---: | ---: |
| 价格1.5、半径3公里 | 635 | 35,560 | 0 |
| F3：价格1.6、半径2公里 | 3,404 | 190,624 | 0 |

这些转移在轨迹内相关，不能作为数万次独立试验。留出数据上，每种历史各抽512个状态，五个初始化的独立和自回归IQL均100%贪心延续各自历史动作；因此模型能够输出F3，但在预热历史下几乎确定地选择继续预热动作。

该结果指向历史条件下缺少动作切换对照：整段固定策略数据使历史动作高度识别采集模式，优势加权行为克隆在这些条件下缺少可学习的替代动作。它不是全数据没有动作支持的证明，也不能单靠这项观察确认全部因果来源。

下一项有辨识力的试验是保留现有状态与动作空间，额外采集“统一预热后随机切换”及不同持续时间的决策级探索，设置相同新增轨迹预算的原采样对照，再按训练初始化和新仿真种子比较IQL/BC。保持旧测试集封存，不以改变预热或屏蔽动作制造提升。该数据干预尚未执行；原大规模采集保持暂停。
