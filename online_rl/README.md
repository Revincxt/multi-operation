# 在线联合决策：AR-PPO

六区域部分可观测、有限时域联合控制，以 05:20—10:00 的全城平台累计佣金为目标。采用 MAT 启发的因果动作解码与集中式 PPO，属于 CTCE，是当前问题的适配实现。

## 结构与训练

- 输入：每区四周期历史、当前本区及邻区状态，合计 660 维；包含历史动作，排除当前候选动作、当期结果和未来订单。
- 编码：共享 LSTM 窗口、区域 embedding、全局注意力；每次决策重置窗口 LSTM，不跨整轮保存隐藏状态。
- 解码：区域顺序 0—5，区域内先价格、再条件半径；六区域动作同时提交，全部 110 种组合合法。
- 价值：独立的历史／空间编码器输出全城 V，不使用候选动作 Q 搜索。
- 更新：完整仿真轨迹、γ=1、GAE λ=0.95、完整联合概率比、clip=0.1、每批最多 5 轮更新，联合 KL 控制剩余更新；奖励除以固定 100。

当前方法没有动作禁选、F3 回退或禁止重复。随机祖先采样用于运营评估；逐区域条件众数不是全局联合 MAP。结构对照 `--factorized` 关闭动作前缀，仍保留全局状态信息。

## 运行新的实验

```bash
python3 -m unittest discover -s tests -p test_online_rl.py -v

# 新协议采用代码默认的首阶段预算，输出目录必须是新目录
python3 -m online_rl.protocol --output experiments/online_new
python3 -m online_rl.train --protocol experiments/online_new/protocol.json \
  --output models/online_new/seed81 --training-seed 81 --workers 8
```

真实运行需要本地仿真输入、观测标准化元数据及协议指定的参考模型。恢复已有单组训练时，在相同参数下加 `--resume`；在完整迭代边界保存优化器、随机数、历史和权重。中断的未提交批次会重算。

## 评估约定

共同预热 20 分钟，每轮计分 56 个五分钟决策。六区域合算一次城市级交互，不能把一条联合转移算成六条独立样本。

训练、验证和测试种子分离；验证用于监测，预定预算终点用于正式比较。配对保证订单、司机初态和预热相同，后续随机流不保证动作无关地对齐。多初始化统计应交叉重采样训练初始化与环境种子；六指标中的完成率与等待时间沿用仿真器口径。

`training_history.csv`、`validation_history.csv` 和 `training_curves.*` 保留完整记录。旧的预算扩展过程保留在本地协议和迁移记录，不再逐阶段复制到说明页。

参考：[MAT](https://arxiv.org/abs/2205.14953)、[PPO](https://arxiv.org/abs/1707.06347)、[GAE](https://arxiv.org/abs/1506.02438)。
